## Color palette

### Main colors

- `#DAD7CD` — light neutral base, used for backgrounds and subtle surfaces.
- `#A3B18A` — soft secondary color for complementary elements.
- `#588157` — primary highlight color used for actions and navigation.
- `#3A5A40` — dark support color for titles and high-contrast elements.
- `#344E41` — strong contrast color for headers and institutional highlights.

### Secondary colors

- `#D9EAD8` — success-related color variation.
- `#F1E2C7` — warning and attention states.
- `#EACACA` — error feedback and negative states.
- `#D9E7F4` — neutral information blocks.
- `#E8E3DC` — secondary background areas.
- `#FFFFFF` — cards and form surfaces.
- `#1F1F1F` — primary text and high legibility elements.

## Typography

Use a clean sans-serif typeface with strong hierarchy for titles, subtitles, buttons, and navigation elements.

## Other visual standards

### Spacing system

The interface should follow a spacing scale based on multiples of 4.

- Base space: `4px`
- Recommended scale: `4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80`

### Border radius

- `4px` — chips, badges, and small inputs
- `8px` — secondary buttons and compact cards
- `12px` — inputs and content cards
- `16px` — main cards and panels
- `24px` — large cards and banners

### Shadows

- `shadow-sm`: `0 2px 4px rgba(0, 0, 0, 0.08)`
- `shadow-md`: `0 4px 8px rgba(0, 0, 0, 0.10)`
- `shadow-lg`: `0 8px 16px rgba(0, 0, 0, 0.12)`
- `shadow-xl`: `0 12px 24px rgba(0, 0, 0, 0.14)`

## Icons

The interface should use a modern icon set such as Phosphor Icons.
