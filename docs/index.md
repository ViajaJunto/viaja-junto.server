<h1 style="text-align: center">Welcome</h1>

This documentation contains the specification artifacts for ViajaJunto, a collaborative travel-planning application developed for the Software Construction course.

## About the documentation

This site documents the product vision, functional and non-functional requirements, software architecture, data model, and visual identity of the ViajaJunto platform.

## About the project

Planning a trip with a group is often fragmented and frustrating. Information is dispersed across WhatsApp conversations, spreadsheets, emails, and individual notes, without a central place where all participants can see the complete itinerary, planned activities, and spending. This disorganization creates rework, scheduling conflicts, and lost information, especially when multiple people are involved.

ViajaJunto proposes a web application for collaborative trip planning where a group of users can organize itineraries with multiple destinations, dates, activities, and budgets in one shared environment. The platform also offers an interactive map, a community rating system, and trip recommendations based on the experience of other travelers.
